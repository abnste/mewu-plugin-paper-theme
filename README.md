# Paper

浅色纸张主题，含静态网格背景。需要 MewuAI 1.2.0 或更新版本。

在 Mewu 的插件市场安装，随后在设置 → 通用 → 主题中选择。停用或卸载后恢复默认外观，重新启用会恢复原选择。

插件只声明语义颜色和静态背景，不执行宿主 DOM 或 CSS 注入，不读取文件、对话或凭据。Windows、macOS 与 Linux 使用同一个插件包。

开发协议：[Mewu 外观扩展](https://github.com/abnste/mewu_ai/blob/master/docs/plugin-appearance.md)。开发 SDK：[Mewu SDK](https://github.com/abnste/mewu_ai/tree/master/packages/sdk)。
